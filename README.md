# Cohub CLI — A Claude Code Skill

> Reference skill for the [`@neta-art/cohub-cli`](https://cohub.run) — the official CLI for Cohub, a cloud platform for space-based agent creation and collaboration.

## What Is It

This skill gives Claude Code a concise reference for using the Cohub CLI to interact with spaces, sessions, files, checkpoints, scheduled prompts, search, and multimodal generation. The CLI itself has excellent built-in help (`cohub -h`, `cohub spaces prompt -h`, etc.); this skill provides the essential context and patterns an agent needs to use it efficiently.

## Install

```bash
claude skill install https://github.com/kjx-talesofai/claude-skill-cohub-cli
```

## Usage

Mention Cohub, spaces, sessions, checkpoints, sending prompts, or managing space files — the skill auto-triggers.

See `SKILL.md` for the full command reference and `cohub -h` for exhaustive CLI help.

## Package

`@neta-art/cohub-cli` on [npmx](https://npmx.dev/package/@neta-art/cohub-cli).
